So funktioniert ASCII

Stell dir vor, du schickst deinem Freund eine Zahl, und er soll daraus einen Buchstaben machen. Das klappt nur, wenn ihr beide dieselbe Liste benutzt. Genau so eine Liste ist der ASCII-Code.

Teile:

Ein Zeichen – eine Nummer

Der ASCII-Code ist eine festgelegte Tabelle. Darin hat jedes Zeichen seine feste Nummer: Großbuchstaben, Kleinbuchstaben, Ziffern, Satzzeichen und sogar das Leerzeichen. Der Computer speichert nicht den Buchstaben, sondern nur die Nummer – und die als Binärzahl.

ZeichenH
→ Tabelle →
Dezimal72
→ umrechnen →
Binär (1 Byte)0100.1000

Beim Lesen läuft es genau rückwärts: Bitfolge → Dezimalzahl → im Decoder nachschlagen → Zeichen. Damit man sich bei acht Stellen nicht verzählt, setzen wir nach je vier Bits einen Punkt: 0100.1000.

📖 Dein Decoder

Die ASCII-Tabelle siehst du die ganze Zeit im Decoder-Banner oben. Mit den Reitern schaltest du zwischen Großbuchstaben, Kleinbuchstaben und Ziffern & Sonderzeichen um. Diese Regeln helfen dir, dich schnell zurechtzufinden:

  • Kleinbuchstaben: a = 97, b = 98 … z = 122 (immer genau 32 mehr als der Großbuchstabe)
  • Ziffern als Zeichen: „0“ = 48, „1“ = 49 … „9“ = 57
  • Leerzeichen = 32 · ! = 33 · ? = 63
💡 Der ursprüngliche ASCII-Code nutzt 7 Bit und hat damit 128 Zeichen (Nummer 0 bis 127). Gespeichert wird aber jedes Zeichen in einem ganzen Byte = 8 Bit; die erste Stelle ist dann einfach 0. Buchstaben wie ä, ö, ü und ß gibt es im ASCII-Code nicht – er wurde in den USA für das englische Alphabet erfunden.
📓 Heftereintrag — Der ASCII-Code

ASCII-Code: festgelegte Tabelle, die jedem Zeichen (Buchstabe, Ziffer, Satzzeichen, Leerzeichen) eine Nummer zuordnet.

Speichern: Zeichen → Nummer (Tabelle) → Binärzahl mit 8 Bit (1 Byte). Beispiel: H → 72 → 0100.1000

Lesen: Bitfolge → Dezimalzahl → Tabelle → Zeichen.

Sender und Empfänger müssen dieselbe Tabelle benutzen. Großbuchstabe + 32 = Kleinbuchstabe (A = 65, a = 97).

🔬 Das Bit-Labor

Jeder Schalter ist ein Bit. Klicke ihn an, um ihn zwischen 0 und 1 umzuschalten. Unten siehst du sofort, welche Dezimalzahl und welches ASCII-Zeichen gerade gespeichert sind.

Laborauftrag: Stelle nacheinander die drei Zeichen H, i und ! ein. Hast du ein Ziel erreicht, bekommt es einen Haken.

Suche zuerst die Nummer des Zeichens: im Decoder oben oder in den Regeln aus Teil 1.
Zerlege die Nummer in Stellenwerte: Fange beim größten Wert an, der noch hineinpasst (64? 32? 16? …) und schalte dieses Bit an.
H = 72 = 64 + 8 · i ist ein Kleinbuchstabe: I = 73, also i = 73 + 32 = 105 · ! = 33 = 32 + 1

H = 72 = 64 + 8 → 0100.1000

i = 105 = 64 + 32 + 8 + 1 → 0110.1001

! = 33 = 32 + 1 → 0010.0001

🧪 Probier ruhig auch aus, was passiert, wenn du das Bit mit dem Wert 128 einschaltest. Ab Nummer 128 hört der ASCII-Code auf!

📓 Heftereintrag — Codierung oder Verschlüsselung?

Codierung: Darstellung mit einer öffentlich bekannten Regel (z. B. ASCII). Jeder kann sie zurückübersetzen.

Verschlüsselung: Nur wer den geheimen Schlüssel kennt, kann die Nachricht lesen.

2. Warum kann man das Wort „Grüße“ mit dem ASCII-Code nicht vollständig speichern?
📓 Heftereintrag — Merksatz

Computer speichern Text als Zahlen. Der ASCII-Code legt für jedes Zeichen eine Nummer fest; gespeichert wird sie als Binärzahl in einem Byte (8 Bit). Wer die Tabelle kennt, kann die Nachricht lesen – ASCII ist eine Codierung, keine Verschlüsselung.

★ Der geheime Schlüssel

★ Aufgabe 3: Euer geheimer Schlüssel lautet +3: Zu jedem ASCII-Code wird 3 addiert. Verschlüssele das Wort CODE und gib die neuen Buchstaben an.

Geheimtext:
C = 67 + 3 = 70 = F · O = 79 + 3 = 82 = R · D = 68 + 3 = 71 = G · E = 69 + 3 = 72 = H → FRGH
Suche zuerst die Codes von C, O, D und E – du kennst sie aus Stufe 4.
Addiere zu jedem Code 3 und schlage das neue Zeichen im Decoder nach.
C = 67 → 70 = F. Mach bei O, D und E genauso weiter.

C: 67 + 3 = 70 → F

O: 79 + 3 = 82 → R

D: 68 + 3 = 71 → G

E: 69 + 3 = 72 → H

Der Geheimtext lautet FRGH. Nur wer den Schlüssel +3 kennt, rechnet −3 und liest wieder CODE.

🏛️ Dieses Prinzip mit einem geheimen Verschiebe-Schlüssel nutzte schon Julius Caesar vor über 2000 Jahren. Es heißt deshalb Caesar-Verschlüsselung.

Das hast du gelernt

Der ASCII-Code ordnet jedem Zeichen eine Nummer zu (A = 65). Gespeichert wird die Nummer als 8-Bit-Binärzahl (0100.0001).
Entschlüsseln: Byte → Dezimalzahl → Tabelle → Zeichen. Codieren: Zeichen → Tabelle → Dezimalzahl → Byte.
Die ASCII-Tabelle ist öffentlich. Geheim wird eine Nachricht erst mit einem Schlüssel, den nur Sender und Empfänger kennen.
